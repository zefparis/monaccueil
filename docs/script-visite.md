# Script de visite pilote — 20 minutes

À suivre chez la personne, **avec elle**. Le but est d'observer, pas de faire vite.
Note au crayon les hésitations : ce sont elles qui font avancer le projet.
Prévoir : la fiche `fiche-senior.html` imprimée, le `questionnaire-retour.md`, et
le `accord-test.md` signé avant de commencer.

| Minute | Étape |
|---|---|
| 0–3 | **Installation et navigateur.** Ouvre `index.html` sur le PC (ou le raccourci « Mon Accueil » s'il est déjà installé). Vérifie que la page de démarrage **et** le bouton Accueil pointent dessus. **Teste dans Edge ET dans le navigateur habituel de la personne** : même aspect, mêmes boutons. **Épingle Mon Accueil à la barre des tâches** (clic droit sur l'icône → « Épingler à la barre des tâches ») : c'est le chemin de retour le plus simple. |
| 3–6 | **Démonstration en 3 gestes seulement.** Résiste à tout montrer. 1) « On clique sur un gros bouton » → ouvre « Mes impôts ». 2) « On revient » → premier onglet. 3) « On demande de l'aide » → bouton rouge « J'ai besoin d'aide ». C'est tout. |
| 6–10 | **Moment clé : elle essaie seule.** « À vous, comme si je n'étais pas là. » Elle ouvre un site de son choix, revient à l'accueil, trouve « J'ai besoin d'aide ». Observe **sans aider**, note chaque hésitation dans le questionnaire (temps pour trouver une démarche, boutons cherchés, erreurs). **Observe surtout le retour** : a-t-elle compris que le site s'ouvre à droite ? Cherche-t-elle la croix, l'icône de la barre des tâches, ou panique-t-elle ? Aide seulement si elle abandonne. |
| 10–13 | **Le vérificateur d'adresse.** Ouvre « Un message me paraît bizarre ». Lis les 3 questions à voix haute avec elle. Colle les 4 exemples un par un dans « Vérifier une adresse » et laisse-la dire le résultat :<br>• `https://www.impots.gouv.fr` → **vert**, lis-lui la phrase « le site est le vrai, mais le message peut quand même être une arnaque »<br>• `https://impots.gouv.fr.remboursement-info.com` → **rouge** (sous-domaine trompeur)<br>• `https://www.ameli-assure.fr` → **rouge** (imitation)<br>• `https://bit.ly/xyz` → **rouge** (raccourci)<br>Demande-lui **avec ses mots** : « pourquoi est-ce que le vert ne suffit pas à lui seul ? » Note sa réponse. |
| 13–15 | **Test du bouton d'aide.** Elle appuie sur « J'ai besoin d'aide », lit ton numéro à voix haute. Vérifie si le lien `tel:` fait quelque chose sur ce PC. Si non : note « plan B : numéro écrit en gros » dans le questionnaire, et vérifie qu'il est bien lisible sur la fiche imprimée. |
| 15–17 | **Écran tactile (si le PC en a un).** Au doigt : une tuile, le bouton rouge, l'appui long… non, surtout pas l'appui long (mode technicien) — teste seulement les gros boutons au doigt et le défilement. Note si les boutons sont assez grands. |
| 17–19 | **Remise de la fiche et rappel.** Donne `fiche-senior.html` imprimée. Lis ensemble la ligne du bas : « Je ne vous demanderai jamais un mot de passe ou un code bancaire. » Répète : « En cas de doute, ne cliquez pas, appelez-moi. » |
| 19–20 | **Avant de partir.** Sur **ton** PC (pas le sien) : consigne l'intervention dans le journal (mode technicien → onglet Journal, motif « formation »). Chez la personne, vérifie que rien de personnel n'est resté dans le navigateur : ferme les onglets de test, vide le champ de vérification s'il reste du texte, vérifie que rien n'a été tapé dans un formulaire ou une barre de recherche. Remplis le questionnaire `questionnaire-retour.md` partie « juste après la visite ». |

## Rappels

- Si ça déborde : raccourcis, ne rajoute pas une 21e minute « pour tout montrer ».
- Si la personne est fatiguée, saute le bloc 15–17 et note-le dans le questionnaire.
- Ne laisse jamais le mode technicien ouvert en partant.
