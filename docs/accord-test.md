# Accord de test — Mon Accueil

Entre ____________________________ (qui installe) et ____________________________
(qui teste).

**Ce test est un coup de main entre amis.**

- **C'est gratuit**, et ça le restera. Vous pouvez arrêter quand vous voulez,
  sans vous justifier.
- **Aucune donnée n'est collectée.** Tout reste sur votre ordinateur. Rien n'est
  envoyé sur Internet.
- **Aucun mot de passe ni code bancaire** ne vous sera jamais demandé —
  ni à l'écran, ni au téléphone. Si quelqu'un vous en demande un en mon nom,
  refusez et rappelez-moi.
- **L'aide à distance** se fait seulement quand **vous** appelez, que vous ouvrez
  le logiciel vous-même et que vous acceptez à l'écran. Vous pouvez refuser ou
  couper à tout moment.
- Vous gardez une fiche imprimée avec le numéro de téléphone : appelez, même pour
  une question qui vous paraît bête.

## Pour tout enlever

1. Faites un clic droit sur l'icône « Mon Accueil » du Bureau → « Supprimer ».
2. Faites de même avec l'icône « Aide à distance » si elle existe.
3. Dans le navigateur, remettez la page d'accueil que vous aviez avant.
4. (S'il existe) supprimez le dossier `C:\MonAccueil`.
5. C'est fini. Si vous n'y arrivez pas, appelez-moi, je vous guide ou je le fais.
