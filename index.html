Un message me paraît bizarre

1. Posez-vous 3 questions

  1. On me demande de l'argent, un code ou un mot de passe ?
  2. On me met la pression (urgent, dernier délai, compte bloqué) ?
  3. Ce message est-il inattendu ?

Si la réponse est oui à UNE seule question : ne cliquez pas, ne répondez pas, appelez-moi.

Ne donnez jamais un code reçu par SMS. Ne scannez pas un QR code reçu par message. Une banque ne vous demande jamais de code par téléphone.
